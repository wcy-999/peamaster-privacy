我在末世种豌豆 · 隐私政策

更新日期：2026年11月9日　生效日期：2026年11月9日

开发运营者：汪晨雨（个人开发者）　联系邮箱：1900502733@qq.com

本政策适用于《我在末世种豌豆》Android 游戏，应用包名为 org.peamaster.game。当前 0.1.2 版本的安装名称及部分游戏界面仍显示原名称“碗豆大师”，属于同一款游戏。

我们重视您的隐私。本游戏当前采用本地单机运行方式，无需注册或登录账号，未接入广告、内购支付、在线排行、云存档、实名验证、防沉迷联网验证、行为统计或自动崩溃上报服务。种子邮箱通过玩家自行传递交换码工作，不是联网邮件系统。以下分别说明游戏运行、主动反馈以及访问本政策网页时的信息处理。

一、我们处理的信息及用途二、应用权限三、第三方组件与服务四、信息保存与期限五、共享、转移与公开六、信息安全七、您的选择与信息管理八、未成年人保护九、政策更新十、联系我们

一、我们处理的信息及用途

1. 本地游戏进度。为保存和继续游戏，应用在您的设备内保存植物与种子的基因、名称、成长与生命状态、亲本和来源、分组与保留标记、装车配置、库存资源、研究与繁育任务、任务时间、出征与无尽记录、得分以及音乐等设置。这些是游戏数据，不要求您填写真实姓名、手机号、身份证号、住址等身份资料。请勿将个人敏感信息写入植物或分组名称。

2. 种子交换数据。应用为每份存档随机生成一个邮箱标识，用于判断是否为自己发送的交换码、防止重复领取和记录每日领取数量；它不是从 IMEI、Android ID、广告标识符或其他设备标识推导而来。生成的交换码包含协议版本、发送时间、随机存档标识、随机值、种子基因数据和校验值。编码及校验用于数据交换与误码检测，不是保密加密。获得交换码的人可以解码其中内容，并可能关联同一存档分享的多份交换码。

发件记录会在本机保存交换码、种子编号及名称、发送时间；收件记录会保存交换码校验标识、发送来源、接收时间或日期、每日领取次数，用于展示记录、判重和执行游戏规则。游戏不会代您上传交换码；只有您自行复制并在论坛、聊天等外部应用中发送时，接收人或相关平台才会获得相应内容。

3. 剪贴板。只有您点击邮箱界面的“粘贴”按钮时，应用才读取当时的剪贴板文本并填入交换码输入框，在本机检查格式；点击“复制交换码”时，把您选定的交换码写入系统剪贴板。应用不定时读取剪贴板，不向服务器发送剪贴板内容；您可以手动输入，或不使用这项功能。系统输入法自身的粘贴行为由系统管理。

4. 运行环境。游戏引擎在本机使用运行所需的屏幕、图形、音频和系统环境信息来呈现画面、接收操作及处理错误；我们未配置把这些信息、游戏行为或错误日志自动上传给开发者或统计服务。

5. 主动反馈。若您自行向联系邮箱发送问题，我们会收到邮件地址、邮件内容以及您主动提供的截图、日志或其他附件，用于答复和排查。请只提供与问题有关的内容，并避免发送密码、证件、完整剪贴板或无关个人资料。游戏不会自动代您发送邮件。

二、应用权限

当前 Android 0.1.2 安装包未声明 Android 权限，包括互联网、网络状态、定位、相机、麦克风、通讯录、电话状态及外部存储读写权限。应用私有目录中的存档读写和您主动触发的剪贴板操作不等于申请上述权限。

应用不会以拒绝提供与单机玩法无关的信息为由阻止您游玩。如后续功能需要新的权限或信息处理，我们会先更新说明，并按适用要求在使用前告知和征求授权。

三、第三方组件与服务

游戏使用 Godot 引擎及其 Android 运行所需的 AndroidX、Kotlin 等基础组件，用于图形、音频、输入、界面生命周期及运行兼容；当前未接入第三方登录、广告、支付、行为分析或远程崩溃上报 SDK。基础组件包含某类通用接口，不表示游戏已启用该接口对应的业务功能。

TapTap 的下载、平台账号、社区、评论等服务由平台独立提供，不等于本游戏已接入 TapSDK。您在外部平台发布交换码、截图或评论时，其信息处理适用相应平台的规则。

本政策网页托管于 GitHub Pages。您用浏览器打开网页时，GitHub 可能处理 IP 地址、浏览器或设备信息、访问时间和请求记录，以提供托管及安全服务，具体见 GitHub 隐私声明：GitHub 隐私声明 。本页面不嵌入统计脚本、广告、外部字体或提交表单，不读取您的游戏存档，也不自行设置跟踪 Cookie。网页访问与离线游戏运行是不同场景。

通过邮箱与我们联系时，邮件投递及存储也依赖您和我们使用的邮件服务商，其处理适用各自服务规则。

四、信息保存与期限

游戏进度保存在本机应用私有数据目录，并维护一份本地恢复备份；保存失败或文件异常时，可能保留临时文件或异常恢复副本，以避免损坏已有进度。游戏数据会在您继续使用期间保留，直到被新的进度替换或通过系统清除应用数据等方式删除。当前安装包关闭 Android 自动备份，开发者不提供游戏服务器存档或云同步；设备厂商另行提供的系统迁移或备份功能由您和系统控制。

反馈邮件及附件在处理问题、答复和必要后续核对期间保留；不再需要时删除或作无法识别个人的处理，法律另有保存要求的除外。您可以通过联系邮箱提出删除请求。我们没有可供远程查询或删除的在线游戏账号数据库。

本机游戏数据不会由本游戏发送至境外。您主动使用的外部分享、邮件服务及 GitHub 网页托管的存储地点与跨境处理，以相应服务的实际规则为准，不将其视为游戏本地存档的上传。

五、共享、转移与公开

我们不会出售您的个人信息，也不会为了广告或营销主动共享您的本地游戏进度。仅在处理您主动提出的问题所必需、取得相应授权，或依法需要配合时，处理您提供的信息；将按适用要求告知接收方和处理目的。

您主动发出的种子交换码可能被他人复制、转发或留存。删除本机记录、重新开始游戏或卸载应用，不能撤回其他人或外部平台已经取得的交换码、邮件和截图。如需删除平台上的内容，请使用对应平台提供的入口。

如发生开发运营主体变更等涉及个人信息转移的情形，我们会按适用要求告知有关情况；改变原有处理目的或方式时，依法履行相应程序。

六、信息安全

我们采取与当前单机功能相适应的数据最小化、应用私有目录存储、输入格式与长度校验、保存校验及本地恢复措施，减少无关信息处理和意外损坏。交换码校验仅用于检测输入错误，不提供身份认证或加密保密保证。

请妥善保护设备和系统锁屏。获取设备、应用数据、系统备份或您公开分享内容的人，可能读取其中数据；任何系统都无法保证绝对安全。如发现与本游戏有关的信息安全问题，请通过下述邮箱联系。

七、您的选择与信息管理

查看与修改：您可在温室档案、分组、装车、研究、邮箱及设置等实际游戏界面查看或修改相应游戏数据；音乐等偏好可在设置中调整。

重新开始：标题界面“新游戏”在您确认后替换当前进度及其正常恢复备份，包括种子、资源、研究、任务、分组、邮箱和得分记录，并生成新的存档邮箱标识；音乐等设置会保留。它不是清除全部应用文件的功能，不能保证同时移除异常恢复副本、临时文件或系统日志。

完整清除本机应用数据：在 Android 系统设置中找到本应用（当前版本可能显示“碗豆大师”），使用应用存储中的“清除数据”或同类入口。该操作会删除本机进度、备份和设置，无法从开发者服务器恢复；卸载也通常会删除应用私有数据。系统备份、外部平台内容和剪贴板中的副本需分别由您管理。具体入口名称以设备系统为准。

停止分享或粘贴：不使用相应按钮即可；清空游戏输入框不会自动清空系统剪贴板，您可通过系统或输入法提供的方式管理剪贴板。

反馈信息的权利：对于您主动提供给我们的个人信息，您可通过联系邮箱请求查阅、更正、删除、限制处理或解释说明。我们会在核实必要情况后及时处理，并遵守适用的法定期限；不会为核实请求索取与其无关的信息。本游戏当前没有在线账号，因此没有账号注销入口。

八、未成年人保护

未成年人请在监护人指导下阅读本政策并使用游戏。未满十四周岁的用户如需通过邮件或其他外部服务向开发者提供个人信息，应先取得监护人的同意。

本游戏不以收集儿童个人信息为目的，也不要求填写年龄或身份资料。监护人如发现未成年人向我们提供了不必要的个人信息，可通过联系邮箱申请处理；我们会按适用要求核实并删除或采取其他必要措施。

九、政策更新

游戏名称、功能或信息处理方式发生变化时，我们会更新本政策及更新日期。涉及处理目的、类型、方式或其他重要变化的，将按适用要求在相关处理发生前进行明显告知，并在需要时取得授权；不会以仅更新网页来替代依法必要的告知或同意。当前政策只描述已说明版本的实际处理方式。
